# 灵听 · Lynx 界面原型交付概览

## 已完成
- 制作单文件可点击高保真 HTML 原型（v3 自包含：内嵌子集字体 + logo base64，无需外部资源），适配桌面数据大屏场景。
- 三个一级板块：数据看板、原声列表、游戏对比卡片页（`game-compare.html`，Steam 封面卡 + 词云）。
- **B 站单视频看板**（`bilibili-video.html`，v0.1 简单原型，2026-08-21）：黑神话·钟馗 15 分钟实机演示为核心，4 区块（视频概览/情感总览/主题×情感下钻/弹幕时间轴热力图），ECharts 密度曲线 + 模式散点云 + TOP10 高亮时刻。
- 数据看板包含全局筛选、5 项核心指标、时间趋势、情感扇形分布、渠道柱状分布、高频问题条形排行和声音词云。
- 原声列表包含复用筛选器、文本搜索、来源与渠道、情感标签、时间、分页及详情抽屉。
- 加入导航切换、查询反馈、重置筛选、搜索过滤、分页选中和详情查看等交互。

## 视觉决策
- **Token 权威定义已收口至 `docs/architecture/DESIGN_TOKENS.md`（v1.0，2026-08-31）**：本节仅作历史决策摘要，任何冲突以规范文档为准。浅色主题（ColorHunt `#3368A0` 系）为受限主题，仅用于导出/打印场景。
- 主题：**Steam 蓝黑**（深色）——背景 `#0e141b`、面板 `#1b2838`、主色 `#66c0f4`、强调绿 `#a1cd44` / 红 `#e05c5c` / 黄 `#d9b54e`（见 `prototype/src/base.css`）。
- 风格：现代企业级、高信息密度、卡片式分析布局。
- 注：早期浅色方案（`#78A4CB` 等）已弃用，以深色 Steam 蓝黑为准。
- **B 站看板 v0.1**（2026-08-21）：沿用 Steam 蓝黑主题保持品牌一致；弹幕时间轴新增 暖 `#f59e0b` / 冷 `#3b82f6` 情绪色信号；不内嵌字体子集（用系统字体栈）；ECharts CDN 加载（`echarts@5.5.0`）。
