# DESIGN_TOKENS.md — 灵听 Lynx 设计 Token 规范

> **版本**：v1.0 · **日期**：2026-08-31 · **状态**：已评审，待前端执行
> **适用范围**：`product/prototype/` 全部页面（主看板 / 游戏对比 / B 站看板）及后续前端组件化
> **来源**：三原型 UI/UX 评审结论的落地规范。冲突时以本文档为准；`product/prototype_overview.md` 仅作历史决策摘要。

---

## 1. 设计原则

1. **简约**：一个概念只有一个 token；组件禁写裸值，一切颜色/圆角/阴影引用变量。
2. **现代**：深色优先（dark-first），卡片式布局，层级靠 border 而非重投影。
3. **逻辑清晰**：语义色（正/中/负）是全站唯一情感编码，任何页面不得另立色彩语义。

**主题策略**：深色 Steam 蓝黑 = 默认主题（游戏语境 + 长时盯屏场景）。浅色主题（ColorHunt `#3368A0` 系）= 受限主题，**仅**用于报告导出 / 打印 / 日间分享页，不作为默认 UI。

| `--bg2` | `#101822` | 次级底（footer / 输入框底） |
| `--panel` | `#1b2838` | 主面板 / 卡片 |
| `--panel2` | `#16202d` | 面板内嵌区块 |
| `--panel3` | `#1f2e40` | hover 态 / 浮层 |
| `--line` | `#2a3f5f` | 主边界线 |
| `--line2` | `#223349` | 次级分隔线 |
| `--line3` | `#31476a` | 强调边界（浮层/弹层） |
| `--ink` | `#e7ecf1` | 一级文字 |
| `--ink2` | `#c7d5e0` | 二级文字 / 卡片标题 |

| `--dim` | `#5c7285` | ⚠️ 仅限装饰性文字（图例注脚/占位符），**禁用于正文**（≈3:1 不达标） |

### 2.2 语义色（全站唯一情感编码）

| Token | 值 | 用途 |
|---|---|---|
| `--pos` | `#a1cd44` | 正面 / 推荐 / 上升 |
| `--neu` | `#d9b54e` | 中性 / 警示 |
| `--neg` | `#e05c5c` | 负面 / 不推荐 / 危险 |
| `--pos-bg` / `--neu-bg` / `--neg-bg` | 对应色 14% alpha | 徽章/标签底色 |
| `--pos-line` / `--neu-line` / `--neg-line` | 对应色 30% alpha | 徽章/标签边线 |

**评级五色归并**（Steam 评级沿用五色，但必须是语义族别名，禁裸值）：

| Token | 引用 | 评级 |
|---|---|---|
| `--rating-best` | `var(--primary)` | 好评如潮（Steam 惯例蓝） |
| `--rating-great` | `var(--pos)` | 特别好评 |
| `--rating-good` | `#9bbf55` | 好评 |
| `--rating-mixed` | `var(--neu)` | 褒贬不一 |
| `--rating-bad` | `var(--neg)` | 差评系 |

**B 站弹幕情绪（仅限弹幕图表）**：`--warm: #f59e0b`（激动）、`--cool: #3b82f6`（吐槽）。不得扩散到评论情感编码。

### 2.3 浅色主题（受限，`[data-theme="light"]`）

基于 ColorHunt `#3368A0 / #66A3BF / #C8DFDB / #F2EFE7`，**含三处强制修正**：

| Token | 值 | 修正说明 |
|---|---|---|
| `--bg` | `#F2EFE7` | 米白底（原色板直用） |
| `--bg2` | `#ECE8DD` | 次级底（派生） |
| `--panel` | `#FFFFFF` | ⚠️ **不用 `#C8DFDB`**：与底色仅 1.2:1 层级失效，且灰绿白作面板显脏 |
| `--panel2` | `#F7F4EC` | 内嵌区块 |
| `--accent-surface` | `#C8DFDB` | 降级为装饰面 / 标签底，禁作主面板 |
| `--line` | `rgba(51,104,160,.18)` | 边界线（面板/底明度差不足，**层级强制靠 border**） |
| `--ink` | `#1e2a38` | 一级文字 |
| `--ink2` | `#33465c` | 二级文字 |
| `--muted` | `#5b6b7c` | 辅助文字 |
| `--primary` | `#3368A0` | 主色（白字 5.8:1 ✓，可承载实心按钮） |
| `--primary-hover` | `#2a5787` | hover |
| `--secondary` | `#66A3BF` | ⚠️ 仅图表系列色 / 大图标（白字 2.8:1，**禁作白字按钮/徽章底**） |
| `--pos` | `#3f6620` | 正面（米白底上 5.8:1 ✓） |
| `--neu` | `#7a6116` | 中性（5.1:1 ✓） |
| `--neg` | `#a83232` | 负面（5.7:1 ✓） |
| `--warm` / `--cool` | `#d97706` / `#2563eb` | 弹幕图表系列色（图形 ≥3:1，禁小字） |

### 2.4 对比度红线（验收必查）

- 正文文字 ≥ 4.5:1；大号文字（≥18px 或 600+ 粗）/ 图标 ≥ 3:1。
- 面板与底色明度差 < 1.5:1 时，**必须**加 `1px` 边界线（深浅两主题同规）。
- 徽章/标签 = 语义色文字 + 14% alpha 底 + 30% alpha 边线，三段缺一不可。

## 3. 字体与排版

| 项 | 规范 |
|---|---|
| 字体栈 | `"OPPO Sans", Inter, "PingFang SC", "Microsoft YaHei", sans-serif`（三页已统一，保留） |
| 等宽 | `Menlo, Consolas, monospace` —— 仅限 ID / 时间戳 / 分数 |

| 字阶 | 10 图例注脚 · 11 徽章次级 · 12 辅助 · 12.5–13 正文 · 13.5 列表正文 · 14 卡片标题 · 17–18 区块标题 · 22 页面标题 · 32 KPI 数字 |
| 行高 | 标题 1.2–1.3 / 正文 1.5 / 长文引述 1.6–1.7 |

## 4. 间距 / 圆角 / 阴影 / 层级

| Token | 值 | 用途 |
|---|---|---|
| 间距基网 | 4px | 常用 6 / 8 / 10 / 12 / 14 / 16 / 18 / 20 / 24 / 28 |
| `--r-sm` | `6px` | 徽章 / chip / 小按钮 |
| `--r-md` | `8px`–`10px` | 按钮 / 输入框 / icon-btn |
| `--r-lg` | `12px` | 卡片 / 筛选面板 |
| `--r-xl` | `14px` | 大区块（B 站 section / 封面卡） |
| `--shadow` | `0 8px 28px rgba(0,0,0,.45)` | 深色主题卡片 |
| `--shadow-pop` | `0 16px 40px rgba(0,0,0,.55)` | 浮层 / 弹层 |
| 浅色 shadow | `0 2px 10px rgba(30,42,56,.08)` | 浅色主题（弱化） |

**层级规则**：面板分离优先用 border（`--line`）；shadow 仅用于浮层（popover / toast / tooltip）。禁止无边界线的纯明度差面板。

## 6. 图标规范

1. **功能图标一律 inline SVG**（stroke 1.5，尺寸 14 / 16 / 20 三档），禁止 emoji /  unicode 字符（⇄ ▼）充当功能图标。
2. emoji 仅允许出现在**用户内容引述**（评论原文、弹幕原文）中。
3. **一图标一语义**，禁止同图标表二义。当前必须修复：B 站页「播放」与「弹幕」同为 ▶ → 播放 = play，弹幕 = 滚动字幕形 SVG。
4. 区块标题装饰图标（🔍 🔥 ⚠️）→ 替换为 SVG 或删除，二选一，全站一致。
5. 品牌 logo 统一使用 SVG 字标资源（`product/prototype/logo/`），禁止 🎙️ 代替。

---

## 7. 图表规范

1. **统一 ECharts（≥5.5）**。禁止新增手写 SVG 图表；存量手写图表（主看板折线/柱图）在组件化阶段迁移。
2. 图表颜色必须取自 token（JS 内 `getComputedStyle` 读取，禁写死 hex）：
   - 轴线 / 网格：`--line2`；刻度文字：`--muted`；图例：`--ink2`；tooltip：`--panel3` 底 + `--line3` 边。
3. 系列色取色顺序：`--primary` → `--pos` → `--neu` → `--neg` → `#4f94cd` → `--warm` → `--cool`，按序取用，禁随机色。
4. 情感堆叠条固定 `--pos / --neu / --neg` 顺序，全站一致。
5. **词云按情感着色**（pos/neu/neg）；无情感数据时单色 `--primary` 并必须在图下注明「仅词频」。

## 8. 主题机制与文件组织

- **单一来源**：新建 `product/prototype/src/tokens.css`，结构为 `:root{ /* 深色全量 */ }` + `[data-theme="light"]{ /* 浅色覆写 */ }`。三页一律 `<link>` 引用，**删除各自内联 `:root` 重定义**。
- 页面根元素 `<html data-theme="dark">`；切换 = `document.documentElement.dataset.theme = 'light'`。
- 组件 CSS / JS 中出现裸 hex（token 定义文件除外）= 验收不通过。

```css
/* tokens.css 骨架 */
:root{ --bg:#0e141b; /* …深色全量，见 §2.1/2.2 */ }
[data-theme="light"]{ --bg:#F2EFE7; --panel:#FFFFFF; /* …浅色覆写，见 §2.3 */ }
```

## 10. 验收清单（前端完成后逐项过）

- [ ] 对比度抽检通过（正文 ≥4.5:1，含 `--muted` 以上所有正文场景）
- [ ] 无 emoji / unicode 字符充当功能图标；播放与弹幕图标已拆分
- [ ] footer 无遮挡（每页滚动到底目检）
- [ ] 图表全部 ECharts，颜色取自 token；深浅主题切换不丢色、不丢图例
- [ ] 浅色主题仅在导出/分享页试点，默认 UI 保持深色
